# Consultor de investimentos

Front-end em React, TypeScript, Vite, Vitest, Oxlint e Oxfmt para consumir respostas JSON do Gemini.

## Como rodar

```bash
npm install
cp .env.example .env
npm run dev
```

Preencha `VITE_GEMINI_API_KEY` no `.env` antes de gerar recomendacoes.

## Scripts

```bash
npm run dev
npm run build
npm run test
npm run lint
npm run format
npm run format:check
```
